# Changelog

## 0.2
- Text compare: connectors and overview map, intra-line highlights, ignore white space / case / regex rules, replace rules, three-way merge with conflicts, folder compare, large-file compare, reports (HTML, text, patch), sessions.
- Command line: `--compare A B`, `--merge BASE LEFT RIGHT --output FILE`, `--compare-folders A B` (exit code 0 same, 1 different, 2 error).
- Word-style mini toolbar on right-click and a Paragraph toolbar (lists, indent, sort, alignment, line spacing, shading, borders).
- Faster compare of big files and faster loading of formatted text.
- Code folding (brackets, indentation, Markdown headings, HTML tags), Go to Definition / Find References / Go to Symbol, plugins.
- Format Document, Minify JSON, Check Syntax; 20+ more languages; bracket-pair highlight, auto-close, indent guides.
- Command palette (Ctrl+Shift+P) and Quick Open (Ctrl+P); multiple cursors and column selection; split view.
- Compare files (side by side), Git status in the tree and change bars in the margin, Run current file, macros.
- Print / export to PDF and HTML, hex view, `.editorconfig`, more themes and a font choice, optional update check.
- Large files: follow (tail -f) and Filter lines.
- Spell check with auto-correct, word autocomplete, bold / italic / underline / size marks, compressed crash-safe session restore.

## 0.1
- First preview: tabs, syntax colours, find / replace / find in files, workspace, large file mode, picture paste.
